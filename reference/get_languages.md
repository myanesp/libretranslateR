# Get a list of supported languages for your working instance

Run this function and you will be able to know the supported languages
for this instance and also their ISO-639 code, needed to set the from
and to languages when using
[`translate()`](http://me.marioyanes.es/libretranslateR/reference/translate.md)
function.

## Usage

``` r
get_languages()
```

## Examples

``` r
if (FALSE) { # \dontrun{
get_languages()
} # }
```
