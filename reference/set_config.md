# Set the LibreTranslate instance you want to use and the API key if needed

This configuration wizard will help you to configure the LibreTranslate
instance you want to use. It also support storing the API key and
exporting the configuration in a .json file that can be read later with
[`import_config()`](http://me.marioyanes.es/libretranslateR/reference/import_config.md)
to avoid running this command every time you initiate R.

## Usage

``` r
set_config()
```

## Examples

``` r
if (FALSE) { # \dontrun{
set_config()
} # }
```
