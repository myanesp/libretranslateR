# Automatically detect the language of a given string

You don't know in which language is a string written? Detect it using
this function.

## Usage

``` r
detect_language(str)
```

## Arguments

- str:

  The string you want to detect the language

## Examples

``` r
if (FALSE) { # \dontrun{
detect_language("what language is this?")
} # }
```
