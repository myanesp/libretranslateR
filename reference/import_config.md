# Import configuration for an instance for a file

Read the file that contains your instance and the API key for it (if
needed), instead of having to execute the
[`set_config()`](http://me.marioyanes.es/libretranslateR/reference/set_config.md)
wizard again.

## Usage

``` r
import_config(file)
```

## Arguments

- file:

  .json file generated by
  [`set_config()`](http://me.marioyanes.es/libretranslateR/reference/set_config.md)
  with the needed information

## Examples

``` r
if (FALSE) { # \dontrun{
import_config("my-custom-instance.json")
} # }
```
